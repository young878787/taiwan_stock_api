# 策略：台股量能反轉 volume_change_5d

LLM（RD-Agent fin_factor、ling-3.0-flash-fin）自動演化出的第一個通過樣本外驗證的台股策略。2026-08-30 保存；2026-08-31 報酬口徑改為復權含息並重驗（訊號存活）。

## 策略邏輯

- **因子**：`volume_change_5d` = 近 5 日成交量變化（詳見 `factor.py`，RD-Agent 生成的原始碼）
- **訊號**：每 20 個交易日，對台股前 100 檔（依代碼排序）計算因子並排名，**買進量能變化最小的 5 檔**（反轉：量能萎縮 → 之後補漲），等權 1/5
- **緩衝帶**：持倉跌出前 10 名才換股（`--buffer 10`），掃描 5/10/15/20/30 名後選定的甜蜜點（夏普最高、回撤最低）
- **成本**：手續費 0.1425%×2 + 證交稅 0.3%（來回 0.585%），台股純現金，不計借貸成本
- **無前視偏差**：t 日收盤訊號、t+1 日生效（kstock 回測引擎保證，見 `test_portfolio_backtest_no_lookahead`）
- **執行時點（定案）**：**以 t 日收盤價成交為主**——對應台股盤後定價交易（13:40–14:00，以 13:30 收盤價撮合；
  量能因子需收盤後才確定，盤中無法搶先）；**t+1 收盤為保守對照**（edge 保留 88%，見 `exec_timing_report.md`）。
  實盤需注意盤後定價流動性薄、每槽 20% 資金能否吃滿

## 為什麼選這個因子

| 檢驗 | 結果 |
|---|---|
| 全樣本 IC（5 日前瞻） | -0.0137，t 顯著 |
| 樣本外 IC（2024-12 之後） | **-0.0178（t=-2.65），比樣本內更顯著** |
| 因子資料依賴 | 只用 `$volume`，**免疫於復權因子缺陷**（見下方資料驗證） |
| 同批對照 | `ma_deviation_20d`（價格類）OOS IC 消失（t=0.57），判定 in-sample 假象而淘汰 |

## 績效（2021-01 ~ 2026-08，台股前 100 檔、top-5、20 日再平衡、緩衝帶 10 名、含成本、復權含息）

| 指標 | 策略 | 基準（TAIEX 報酬指數含息） |
|---|---|---|
| 年化報酬 | **+46.7%** | +27.1% |
| 夏普 | **1.42** | 1.24 |
| 最大回撤 | **28.1%** | 28.5% |
| 換倉比例/次 | 89% | - |

緩衝帶效果（無緩衝 → buffer 10）：年化 +42.7% → +46.7%、夏普 1.34 → 1.42，換倉 94% → 89%。

### 逐年（排除單一年度暴漲/暴跌的疑慮）

| 年度 | 策略 | 大盤含息 | 超額 |
|---|---|---|---|
| 2021 | +63.2% | +25.6% | +37.6% |
| 2022 | +2.8% | -18.7% | +21.5% |
| 2023 | +25.1% | +31.5% | **-6.4%** |

- 6 年中 5 年超額為正；唯一輸的 2023 是大多頭（大盤 +31.5%），屬預期內的反轉策略特性
- 2022 空年防禦佳：+2.8% vs 大盤 -18.7%
- 報酬非單一年度貢獻

### 樣本外（OOS 2024-12 ~ 2026-08，方向僅由 IS 決定）

- OOS 淨年化 +47.7%、夏普 1.26；同期大盤 +56.4%（多頭大行情）→ 相對超額 -8.7%
- **訊號真實存活**（OOS t=-2.65），但相對 buy-and-hold 尚未轉正——2025~2026 為罕見大多頭，大盤買入持有極難打敗
- 逐年表現（見 backtest_report.md）顯示 2022 空年策略 +2.8% vs 大盤 -18.7%，防禦特性明確

### 復權含息口徑重驗（2026-08-31）

- 此前報酬以**未復權原始價**計算，除息日股價自然回落被誤判為虧損、現金股利未計入
- 改用 `$close × $factor`（FinMind 除權息事件向後調整）後：策略年化 +43.9% → **+46.7%**、OOS 淨年化 +41.3% → **+47.7%**、OOS IC -0.0196 → -0.0178（t=-2.65 仍顯著）
- 基準同步上修 +25.9% → +30.5%（等權宇宙股息更多）→ 相對超額小幅收斂，結論不變（現行基準已定格 **TAIEX 報酬指數含息**，等權僅留作對照，見 `benchmark_compare.md`）
- 舊口徑的 IC 略被高估（除息懲罰高股息股）；新口徑下訊號仍存活，**不是假 alpha**

### 執行時點對照（exec_timing_report.md，2026-08-31）

回測隱含「t 日收盤價成交」（盤後定價口徑）；同一訊號改以次日用什麼價成交，檢驗 alpha 對 t→t+1 隔夜/開盤反應段的依賴：

| 執行時點 | 淨年化 | 夏普 | 最大回撤 |
|---|---|---|---|
| t 收盤（回測假設） | +46.7% | 1.42 | 28.1% |
| t+1 開盤 | +43.5% | 1.35 | 28.3% |
| t+1 收盤（最保守） | +40.9% | 1.27 | 30.1% |

- 隔夜段（t收盤 − t+1開盤）僅貢獻 **+3.2pp/年**、日內段 +2.6pp/年；最保守執行仍保住 **88%** 的 edge
- **對「收盤後消息、價已先動」的脆弱度低**：即使完全錯過訊號夜的跳空，策略依舊有效——alpha 來自量能萎縮後的慢速補漲，而非消息反應段

## 交易明細（`--trades`）

`--trades` 會在報告同目錄輸出 `trades_<因子>.csv`（OOS 模式為 `oos_trades_<因子>.csv`），一列＝一筆完整交易，並在報告尾端附摘要。

- **成交時點**：建倉/出場皆以**訊號日收盤價**成交——回測引擎的隱含假設，對應台股實務即**盤後定價交易**（13:40–14:00，以 13:30 收盤價撮合；量能因子需收盤後才確定，盤中無法搶先）。注意盤後流動性薄，實盤需評估能否吃滿 20% 槽位。
- **淨報酬**：進場日 (1+r−fee) × 持有日 (1+r) × 出場日 (1−fee)，與回測引擎逐槽複利完全一致；fee 單邊 = 手續費 + 證交稅/2 + 滑價。
- **報酬口徑**：毛/淨報酬以**復權價**計（含股息；除息日不再是假虧損），成交價 `entry_price`/`exit_price` 為原始價（實際金額）——兩者差額即持有期間股息。
- **持有交易日**以標的自身壓縮序列計（缺價/停牌日不計）——即回測口徑，實務上停牌無法出場。

| 欄位 | 說明 |
|---|---|
| `status` | closed=已平倉、open=樣本結束仍持倉 |
| `entry_date` / `entry_price` | 建倉訊號日 / 當日收盤成交價（原始價） |
| `exit_date` / `exit_price` | 出場訊號日 / 當日收盤成交價（原始價；open 時為最後標記價） |
| `holding_days` | 持有交易日（壓縮序列） |
| `factor_value_at_entry` / `rank_at_entry` / `universe_size_at_entry` | 建倉日因子值、橫截面排名、宇宙檔數 |
| `gross_return` / `net_return` | 毛報酬 / 含來回成本淨報酬（皆復權含息口徑） |
| `exit_reason` | 跌出緩衝帶（第 X 名）、因子值缺失（停牌/壞資料） |
